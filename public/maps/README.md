# Navy Yard map

`navy-yard.svg` is a static illustration derived from OpenStreetMap data retrieved through
Overpass on September 12, 2026. It loads locally without a third-party map embed, API key,
location permission, or client-side map library. Directions links open Google Maps only when
selected. The visible caption credits [OpenStreetMap contributors](https://www.openstreetmap.org/copyright).
OpenStreetMap data is available under the Open Database License (ODbL).

The 640 × 520 illustration projects longitude linearly from −77.0102 to −76.9985 and latitude
from 38.8771 (top) to 38.8697 (bottom). Streets and water outlines retain their source geometry;
minor paths are omitted. Venue pins use building bounds midpoints, except Solace's POI node.
Pins indicate properties, not specific entrances or walking routes.
